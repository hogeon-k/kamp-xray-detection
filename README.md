# KAMP X-ray 512장 최종 분석

`KAMP_Xray_Final_Analysis.ipynb`와 `KAMP_Xray_Submission/KAMP_Xray_Final_Analysis.ipynb`는 동일한 최신 분석 내용으로 맞췄습니다.
제출할 때는 필요한 입력과 실행 안내를 갖춘 **KAMP_Xray_Submission 폴더 전체**를 사용하세요.

노트북 실행 환경은 `requirements-notebook.txt`로 설치합니다.
`requirements.txt`는 기존 모델 학습 환경의 참고 기록입니다.

라벨 출처를 원본 파일까지 다시 확인한 결과는 `outputs/submission_label_audit/검토결과.md`에 있습니다.
과거 XML–YOLO 차이 이력 23장과 최종 선택 라벨의 현재 일치 상태를 구분해 수정했습니다.
원본 dataset과 과거 검토 자료는 그대로 보존했습니다.

제출본 실행 방법은 `KAMP_Xray_Submission/README.md`를 참고하세요.
